# Removing objects, rigs or people

Strategy: 2D. Stages: 04 (if moving), 09.

Steps:
1. Best: a clean plate shot on set. Track it to the shot and roto it in.
2. Locked camera without a clean plate: build one from frames where the area is visible.
3. Moving camera: project a clean frame onto proxy geometry from the tracked camera.
4. AI fill only as a tool, frame-consistent, and only if the user allows it.
5. Re-grain the patch.

Checks: no boiling or swimming patch in motion; grain matches.
