# Set extension or matte painting

Strategy: 2.5D. Stages: 04, 05, 08, 09.

Steps:
1. Track; find where the real set ends.
2. Far elements: painted or rendered stills on cards at their real distance. Near elements: real 3D.
3. Atmosphere grows with distance (Mist pass); far elements lower contrast and bluer.
4. Blend the seam with dust, foliage or architecture that hides the join.

Checks: parallax correct as the camera moves; far elements not sharper than the plate.
